# Top Scope — лендинг коворкинга

Лендинг для коворкинга Top Scope: от макета в Figma до чистой вёрстки. Проект для портфолио, где я прошёл полный цикл — сам спроектировал интерфейс и реализовал его в коде.

## О проекте

Страница рассказывает о коворкинге Top Scope и мотивирует записаться на пробный день. Макет сделан самостоятельно в Figma: сетка, типографика, цвета и компоненты продуманы лично, а вёрстка строго соответствует дизайну — все отступы, скругления и тени перенесены в код.

## Что реализовано

- **Дизайн → код.** Макет спроектирован в Figma и аккуратно перенесён в HTML/CSS: соблюдены пропорции, сетка и визуальные детали.
- **Слайдер отзывов на Swiper.** Реализован слайдер с инициализацией через JS.
- **Кастомная форма с валидацией.** Кастомный чекбокс, кастомные поля ввода, обработка ошибок и состояния focus — чтобы пользователю было удобно взаимодействовать с формой.
- **Модульная структура CSS.** Стили разнесены по файлам (variables.css, components.css, form.css, style.css) для удобства поддержки и масштабирования.
- **Якорная навигация.** Прокрутка к секции формы через data-scroll-to реализована без конфликтов стилей между кнопками и ссылками.
- **Чистота кода.** Для автоматического форматирования используется Prettier — код всегда выглядит единообразно, с правильными отступами и без лишних пробелов.

## Стек технологий

- HTML5, CSS3, JS
- Swiper (слайдер)
- Git
- Prettier (форматирование кода)

## Структура проекта

- `index.html` — основная страница
- `css/` — стили (variables, global, fonts, components, form, style)
- `img/` — изображения и иконки
- `scripts.js` — клиентская логика (скролл, валидация, инициализация Swiper)
